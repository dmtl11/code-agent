Code Agent 项目实现说明

Code Agent 是一个轻量编程智能体项目。它以 Python 实现任务编排，将模型请求、仓库检索、代码编辑、命令验证和结果反馈组织成循环，提供网页与命令行入口。项目关注的不只是生成代码，而是让模型获得可执行、可检查、可持续推进任务的工程环境。

多模型路由是核心特色。用户选择 Auto 后，系统在每次模型请求前，根据任务类型、输入长度、上下文规模及工具失败进行规则评分。通用任务按难度选择 Qwen Flash、Plus 或 Max，代码任务优先选择 Coder，高复杂度时选择 Max，数学与架构任务分别优先匹配 Math、Max。请求失败后，系统结合候选队列、失败次数和冷却标记继续尝试其他已配置模型，包括 DeepSeek 及经 CloseAI 接入的 ChatGPT、Claude。这是启发式选择与失败级联，不是训练得到的路由模型。

Session 将任务状态与模型解耦。浏览器保存 session_id，服务端校验工作区归属，并为每轮执行分配 run_id。消息、事件、工具调用、记忆、检查点及审查记录写入 SQLite。刷新页面或切换模型后，系统可读取同一会话的历史。未完成工具会被标记为 interrupted，提示下一轮检查，避免把中断当成成功。

记忆系统可与 Hermes 作类比：把值得保留的要点从临时对话中分离。项目通过规则提取任务目标、结果摘要、错误和文件路径，去重、限量后持久化，在后续请求中再注入。当前记忆属于 Session，不等同于 Hermes 的跨会话用户画像、冻结快照或主动记忆工具，也不使用向量检索。

上下文管理与 Claude Code 的压缩思路相近，但采用规则实现。默认预算为三万二千 Token，预留约八千给输出；先截断超长工具结果，再压缩早期消息块，保护当前请求，并保持工具调用与结果成组。系统保存摘要与尾部消息，恢复时主要注入摘要。Token 是字符估算，压缩也不保证所有细节无损保留。

工具层提供代码注册表、按行阅读、目录搜索、局部替换与补丁编辑，并以语法检查和测试验证修改。后台服务工具负责启动、探测、读取日志和停止进程树。Review 展示变更，Monitor 记录用量、延迟和错误率，使执行过程可检查、问题可追溯。
